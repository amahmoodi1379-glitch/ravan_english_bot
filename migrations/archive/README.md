# آرشیو Migration ها (تاریخچه)

این پوشه فقط **تاریخچه** است و نشان می‌دهد دیتابیس live چطور به وضعیت فعلی رسیده.
این فایل‌ها قبلاً روی دیتابیس Cloudflare D1 اجرا شده‌اند.

- برای **فهمیدن ساختار فعلی دیتابیس**، به این فایل‌ها نگاه نکن؛ به‌جای آن
  `migrations/schema.sql` را بخوان (منبع حقیقت).
- این فایل‌ها **immutable** هستند؛ ویرایش یا اجرای دوباره‌شان لازم نیست.
- migration های جدید را در `migrations/` (نه اینجا) بساز و `schema.sql` را هم به‌روزرسانی کن.
  قوانین کامل در `.kiro/steering/database.md`.
